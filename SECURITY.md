# Security

KARADAVI is experimental research infrastructure. Security issues involving the public repository should be handled responsibly.

## Do not disclose sensitive material

Never commit or publish:

- API keys, passwords, tokens, or credentials
- Private datasets or personal data
- Internal service endpoints
- Private deployment configuration
- Secrets copied from the private KARADAVI implementation

If sensitive information is accidentally committed, treat it as exposed and rotate or revoke the affected credential rather than relying on repository deletion alone.

## Reporting

For a suspected security issue, provide a minimal description of the affected public component and the impact without publishing exploit details or sensitive material in a public issue.

KARADAVI's public repository is intentionally separated from private implementation and operational infrastructure.

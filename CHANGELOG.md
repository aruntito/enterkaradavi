# Changelog

All notable public changes to KARADAVI are recorded here.

## [Unreleased]

### Added
- Public v0.1 conceptual architecture and research model.
- Experimental schemas for entity state, claims, evidence, provenance, authority, and trust signals.
- Reference examples for basic state, conflicting claims, provenance chains, and trust evaluation.
- Research notes covering trust representation, contextual authority, uncertainty propagation, and entity resolution.
- Automated JSON/schema validation through GitHub Actions.
- Contribution, security, citation, and public/private-boundary guidance.

### Direction
- Tighten terminology and normative schema requirements.
- Add reproducible experiments around conflicting evidence and uncertainty.
- Establish compatibility and versioning rules before calling any schema stable.

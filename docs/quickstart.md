# Quickstart

You do not need the private KARADAVI implementation to explore the public research surface.

## 1. Understand the model

Read [Architecture](architecture.md), then [Glossary](glossary.md).

## 2. Inspect the data model

Start with `specs/entity-state.schema.json`, then inspect the component schemas for claims, evidence, provenance, authority, and trust signals.

## 3. Run the examples

The examples are deliberately small. Compare the basic entity state with the conflicting-claims and trust-evaluation examples to see how uncertainty and evidence are represented.

## 4. Read the research

Follow the numbered research notes and compare their hypotheses with the current roadmap.

## 5. Contribute

Open a focused issue or branch, document the reasoning, validate the examples, and submit a pull request. See [Contributor Workflow](contributor-workflow.md).

# Active Work

This page tracks the public work that corresponds to KARADAVI's current product and research direction without exposing private implementation details.

## Current implementation themes

The private product has moved from foundation work into an editorial knowledge system.

- Canonical entity representation across **10 knowledge domains**.
- Entity-type normalization so singular/plural route and content variants resolve consistently.
- Structured source extraction into canonical draft data.
- AI-assisted drafting behind a mandatory human editorial gate.
- Separate admin/editorial and public knowledge surfaces.
- Public entity pages designed around useful summaries and connected context.
- Progressive web app foundations for the public experience.
- Knowledge-graph work focused on explicit, traversable relations.

## Editorial invariant

> **AI never publishes.**

The system may use automation to extract, normalize, structure, compare, and draft information. Publication is a human editorial action.

This is more than a product policy: it affects provenance. The system should eventually be able to distinguish machine transformations from editorial approval and published state.

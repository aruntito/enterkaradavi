# Documentation

KARADAVI's public documentation is organized around four layers:

1. **Understand** — architecture, glossary, terminology, and design principles.
2. **Research** — hypotheses, experiments, quality standards, and negative results.
3. **Specify** — schemas, semantics, versioning, and interoperability decisions.
4. **Contribute** — workflow, review, security, and the public/private boundary.

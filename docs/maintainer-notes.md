# Maintainer Notes

## Current public milestone

KARADAVI is at an early specification stage. The public repository is intended to make the model inspectable before private implementation details become relevant.

## What “done” means for v0.x

A research item is complete when its question has been investigated enough to justify a documented conclusion, not merely when a file exists.

A schema is ready for candidate status when its semantics, examples, failure modes, and compatibility implications are understood well enough for external review.

## What not to optimize for

- commit count;
- artificial branches;
- artificial pull requests;
- inflated release numbers;
- unexplained metrics.

The repository should look active because meaningful work is happening, not because activity is being manufactured.

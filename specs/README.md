# Specifications

This directory contains public specifications and schemas for KARADAVI concepts.

## Intended direction

Specifications may define:

- entities and identity references;
- claims and evidence;
- provenance records;
- authority context;
- uncertainty representation;
- trust signals; and
- machine-readable state exchanged between components.

Specifications should be versioned deliberately and should separate normative requirements from experimental proposals.

No specification in this directory should expose private deployment details or depend on unpublished internal implementation.

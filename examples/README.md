# Examples

This directory will contain small, self-contained examples showing how KARADAVI concepts can be represented or consumed.

Examples should favor clarity over framework complexity.

Potential examples include:

- an entity with competing source claims;
- a claim linked to provenance and evidence;
- contextual authority evaluation;
- uncertainty represented explicitly; and
- a machine-readable trust state derived from evidence.

Examples should remain synthetic or use appropriately public material. Do not place private datasets, credentials, or internal service information here.
